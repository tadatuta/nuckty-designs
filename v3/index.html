Begin with the source

Authors keep the words in Markdown. Developers define blocks, elements and the markup around them.

One engine, two inputs

From Markdown to BEMJSON. Content becomes a tree of blocks. nu templates process both content and document blocks, so one engine shapes the whole page.

A place for every page

Your sitemap connects source files to published URLs. Source links in Markdown become website links.

Edit either field to inspect this sitemap example.

sitemap:
  - Home [/, index.md]
  - About [/about, about.md]

This is a sitemap illustration. The complete nuckty build runs in Node.js.

Keep the project yours

Shared blocks, separate sites. Each target has its own sitemap, language and domain. Authors supply translations; nuckty passes hreflang data to the document handler.

Add only the capabilities you need. Galleries, video, commands and build stages use the same extension contract: register(env).
